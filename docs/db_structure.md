# Database Structure Reference

## Overview

| Property | Value |
|---|---|
| Database | PostgreSQL (with `pgvector` extension for vector similarity search) |
| ORM | Prisma (`prisma-client-js`) |
| Connection | `DATABASE_URL` environment variable |
| Extension | `vector` (mapped as `pgvector`) — required for `embedding` and `centroid` columns |

### Running migrations

```bash
# Apply all pending migrations (development)
npx prisma migrate dev

# Apply migrations in CI / production (no schema drift check)
npx prisma migrate deploy

# Reset DB and re-apply all migrations from scratch (idempotency check)
npm run db:reset --workspace=backend

# Regenerate Prisma client after schema changes
npx prisma generate
```

## Entity Relationship Summary

```
Organization ──< OrganizationMember   (one org has many members)
Organization ──< OrganizationSettings (one-to-one, FK on settings side)
Organization ──< Draft                (one org has many drafts; nullable)

Cluster ──< Ticket    (one cluster has many tickets; nullable FK on ticket)
Cluster ──< Draft     (one cluster has many drafts)

Draft ──< DraftEvent  (one draft has many audit events)

User                  (standalone — linked to Firebase Auth via firebaseUid)
```

### Foreign key map

| Child table | FK column | References | On Delete |
|---|---|---|---|
| `Ticket` | `clusterId` | `Cluster.id` | SET NULL |
| `Draft` | `clusterId` | `Cluster.id` | RESTRICT |
| `Draft` | `orgId` | `Organization.id` | SET NULL |
| `DraftEvent` | `draftId` | `Draft.id` | RESTRICT |
| `OrganizationMember` | `orgId` | `Organization.id` | RESTRICT |
| `OrganizationSettings` | `orgId` | `Organization.id` | RESTRICT |

## Model Reference

### `User`

Stores a local mirror of the Firebase Authentication user record. Created on first login.

| Column | Type | Nullable | Default | Description |
|---|---|---|---|---|
| `id` | UUID | No | `uuid()` | Primary key |
| `firebaseUid` | String | No | — | Firebase Auth UID (unique) |
| `email` | String | No | — | User email address (unique) |
| `createdAt` | DateTime | No | `now()` | Row creation timestamp |
| `updatedAt` | DateTime | No | auto | Last update timestamp (auto-managed by Prisma) |

---

### `Ticket`

Represents a closed support ticket ingested from Zendesk or Intercom.

| Column | Type | Nullable | Default | Description |
|---|---|---|---|---|
| `id` | UUID | No | `uuid()` | Primary key |
| `sourceId` | String | No | — | External ticket ID from the source platform (unique) |
| `source` | String | No | — | Origin platform identifier (e.g. `"zendesk"`, `"intercom"`) |
| `subject` | String | No | — | Ticket subject line |
| `transcript` | Text | No | — | Full ticket conversation transcript |
| `embedding` | vector(1536) | Yes | NULL | OpenAI `text-embedding-3-small` embedding of the transcript |
| `status` | `TicketStatus` | No | `PENDING` | Processing lifecycle state |
| `clusterId` | UUID | Yes | NULL | FK to `Cluster`; set once ticket is assigned to a cluster |
| `createdAt` | DateTime | No | `now()` | Row creation timestamp |
| `updatedAt` | DateTime | No | auto | Last update timestamp |

---

### `Cluster`

Groups semantically similar tickets. Triggers draft synthesis when it reaches `minClusterSize`.

| Column | Type | Nullable | Default | Description |
|---|---|---|---|---|
| `id` | UUID | No | `uuid()` | Primary key |
| `centroid` | vector(1536) | Yes | NULL | Average embedding vector of all member tickets |
| `status` | `ClusterStatus` | No | `FORMING` | `FORMING` while accumulating tickets; `READY` when threshold met |
| `createdAt` | DateTime | No | `now()` | Row creation timestamp |
| `updatedAt` | DateTime | No | auto | Last update timestamp |

---

### `Draft`

An AI-generated KB article draft awaiting human review.

| Column | Type | Nullable | Default | Description |
|---|---|---|---|---|
| `id` | UUID | No | `uuid()` | Primary key |
| `title` | String | No | — | Suggested article title (generated by GPT-4o) |
| `content` | Text | No | — | Full article body in Markdown format |
| `status` | `DraftStatus` | No | `PENDING_REVIEW` | Review lifecycle state |
| `clusterId` | UUID | No | — | FK to the `Cluster` that produced this draft |
| `orgId` | UUID | Yes | NULL | FK to `Organization`; scopes the draft to a tenant |
| `publishedUrl` | String | Yes | NULL | URL returned by the KB publish webhook after approval |
| `createdAt` | DateTime | No | `now()` | Row creation timestamp |
| `updatedAt` | DateTime | No | auto | Last update timestamp |

---

### `DraftEvent`

Immutable audit log of every action taken on a draft (created, edited, approved, discarded).

| Column | Type | Nullable | Default | Description |
|---|---|---|---|---|
| `id` | UUID | No | `uuid()` | Primary key |
| `draftId` | UUID | No | — | FK to `Draft` |
| `action` | `DraftEventAction` | No | — | The action taken |
| `userId` | String | No | — | Firebase Auth UID of the actor |
| `userEmail` | String | No | — | Email of the actor (denormalized for display) |
| `timestamp` | DateTime | No | `now()` | When the action occurred |
| `orgId` | UUID | Yes | NULL | Org scope (mirrors the draft's `orgId` for easier querying) |

---

### `Organization`

A tenant workspace. All pipeline data (drafts, settings, members) is scoped to an org.

| Column | Type | Nullable | Default | Description |
|---|---|---|---|---|
| `id` | UUID | No | `uuid()` | Primary key |
| `name` | String | No | — | Human-readable org name |
| `slug` | String | No | — | URL-safe unique identifier (unique) |
| `logoUrl` | String | Yes | NULL | Firebase Storage download URL for the org logo image; used as the circular avatar in the sidebar and team list |
| `createdAt` | DateTime | No | `now()` | Row creation timestamp |

---

### `OrganizationMember`

Maps a user (Firebase UID) to an organization and their role within it.

| Column | Type | Nullable | Default | Description |
|---|---|---|---|---|
| `id` | UUID | No | `uuid()` | Primary key |
| `orgId` | UUID | No | — | FK to `Organization` |
| `userId` | String | Yes | NULL | Firebase Auth UID; `NULL` for pending (email-invited) members |
| `userEmail` | String | No | — | Email address; used to link a pending invite on first login |
| `role` | `MemberRole` | No | `MEMBER` | Access level within the org |
| `joinedAt` | DateTime | No | `now()` | When the member joined or was invited |

---

### `OrganizationSettings`

Per-org configuration for integrations and clustering behaviour. One-to-one with `Organization`.

| Column | Type | Nullable | Default | Description |
|---|---|---|---|---|
| `id` | UUID | No | `uuid()` | Primary key |
| `orgId` | UUID | No | — | FK to `Organization` (unique — enforces one-to-one) |
| `zendeskSubdomain` | String | Yes | NULL | Zendesk subdomain (e.g. `"acme"` for `acme.zendesk.com`) |
| `zendeskApiKey` | String | Yes | NULL | Zendesk API token — stored AES-256-GCM encrypted |
| `intercomToken` | String | Yes | NULL | Intercom access token — stored AES-256-GCM encrypted |
| `kbPublishUrl` | String | Yes | NULL | Webhook URL to POST approved drafts to |
| `clusterThreshold` | Float | No | `0.65` | Cosine similarity threshold for cluster membership |
| `minClusterSize` | Int | No | `5` | Minimum tickets in a cluster before synthesis is triggered |
| `updatedAt` | DateTime | No | auto | Last update timestamp |

## Enums

### `TicketStatus`

Lifecycle of a ticket through the pipeline.

| Value | Description |
|---|---|
| `PENDING` | Ticket ingested but not yet embedded |
| `VECTORIZED` | Embedding generated; ready for clustering |
| `CLUSTERED` | Assigned to a `Cluster` |

### `ClusterStatus`

| Value | Description |
|---|---|
| `FORMING` | Cluster is accumulating tickets; below `minClusterSize` |
| `READY` | Threshold met; synthesis has been (or can be) triggered |

### `DraftStatus`

Review lifecycle of a KB article draft.

| Value | Description |
|---|---|
| `PENDING_REVIEW` | Awaiting human decision in the dashboard |
| `APPROVED` | Accepted by a reviewer; published to KB webhook |
| `DISCARDED` | Rejected by a reviewer; removed from active queue |

### `DraftEventAction`

Allowed values for the `DraftEvent.action` audit field.

| Value | Description |
|---|---|
| `CREATED` | Draft was first generated by the synthesis worker |
| `APPROVED` | Reviewer approved the draft for publishing |
| `DISCARDED` | Reviewer discarded the draft |
| `EDITED` | Reviewer saved edits to title or content |

### `MemberRole`

Access level of an `OrganizationMember`.

| Value | Description |
|---|---|
| `ADMIN` | Full access: can invite/remove members, change roles, update settings |
| `MEMBER` | Read/write access to drafts; cannot manage team or settings |
